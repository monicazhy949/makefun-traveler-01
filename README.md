# One Sentence for a Traveler from 1800

A program that writes one sentence of at most 200 characters explaining the
modern internet to a time traveler from 1800, to `/output/entry.txt`.

The sentence builds only from things a person from 1800 already knows — a
road, a post office, a library, a market, a letter, ink — and leaves one
picture: one road joining them all, and a letter read at any door before
the ink dries.

Run it with `python3 main.py`.
